# Torn City & Foreign Stock Watch - fork Workaround

Fork de **Torn City & Foreign Stock Watch** (auteur : Djfowler1991, licence MIT, [Greasy Fork](https://greasyfork.org/en/scripts/596452-torn-city-foreign-stock-watch)) : les heures de recharge estimées s'affichent dans le fuseau du navigateur au lieu du TCT. Le reste est identique à l'original.

## Installation

Avec Violentmonkey ou Tampermonkey, ouvrir [torn-stock-watch-fork.user.js](https://raw.githubusercontent.com/LittleBigDev/torn-stock-watch-fork/main/torn-stock-watch-fork.user.js) et confirmer. Les mises à jour arrivent ensuite automatiquement.

Le script demande une clé API **Public Only**.
